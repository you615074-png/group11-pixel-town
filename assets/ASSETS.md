## B. 角色部件 `kenney-roguelike-characters/.../roguelikeChar_transparent.png`（54×12）

**叠放顺序**：身体 → 裤子 → 鞋子 → 上衣 → 头发 → 帽子 → 手持物。
所有部件都在同一 16×16 框内，直接同格对齐叠放即可。

### B1. 身体与四肢
| 层 | 坐标 | 说明 |
|---|---|---|
| 身体（浅/中/深肤色） | (0,0)(1,0) / (0,1)(1,1) / (0,2)(1,2) | 偶数列无嘴，奇数列带嘴 |
| 绿色兽人 | (0..1, 3) | **禁止使用** |
| 裤子 | (3, 0..9) | 每行一种颜色 |
| 鞋子 | (4, 0..9) | 与裤子行号对应；`(4,4)` 是棕鞋配牛仔裤 |

裤子行颜色（核对）：0 深灰/炭黑，1 棕，2 灰，3 奶油，4 牛仔青（鞋为棕），5 橙，6 青绿，7 紫，8 绿，9 棕+紫。

### B2. 上衣
`6..17` 列 × `0..9` 行；不同列是不同领口/背带/短袖款式，行是色系。
本项目使用的“完整上衣”安全坐标：
`(8,0) 橙 (8,2) 橙 (8,5) 绿 (8,7) 绿 (8,8) 红橙 (14,5) 黑 (14,2) 紫 (10,0) 青 (10,9) 奶油 (6,9) 绿`
——这些格子的衣服能覆盖躯干。`(8,3)`、`(10,1)` 等格子的部分款式是开襟/背心，会露出胸口，避免用于默认统一造型；
旧目录里 `(8,13)`、`(7,11)`、`(8,10)` 等行号超出 0..9，实际会取到空白，已在本项目数据中修正。

## D. 本项目数据约定与核对结论（2025-11 第二轮）
- `data/town.json` 的 `avatar` 使用 `[col,row]` 数组：`body / pants / shirt / hair / hat`；
  `prop` 为对象（角色图集 / 场景图集 / 自定义图标）。本项目默认村民统一 `[1,0]` 身体、`[3,1]` 裤子、
  `[23,0]` 头发、无帽子无道具，仅衣服颜色按房间号确定。
- 角色图集和场景图集的 17px 步长、16×16 尺寸正确。
- 旧目录的发色规则、上衣行号、地板 3×3 平铺方式、预制房屋包围盒有误，均已在本文件修正。
- `js/map.js` 中的预制品数据直接从 `sample_map.json` 的 Objects / Doors/windows/roof 层裁剪，
  并对墙体与屋顶分别做主题色轻染；地表使用无缝瓦片 + 3×3 圆角路/水池，避免“棋盘格”伪影。
